# 工业传感器、机器视觉与精密测量产业链专题

> 研究定位：面向 A 股行业轮动与 ETF 研究，分析制造业感知、检测、定位和测量环节。公司仅为研究样本，不构成买卖建议。行业数据截至 2026-10-12；所有最新经营数据应回到公司公告和统计原文核验。

## 一、核心判断：关注“量产与盈利”，不要只看机器人或 AI 概念

工业传感器、机器视觉和精密测量是智能制造的感知层，服务于工件识别、定位、缺陷检测、尺寸测量、设备状态监测和机器人环境感知。2026 年工业生产数据中，传感器、工业控制设备和机器人相关产品表现较强，但单一产品产量增长不能直接推导到某家上市公司的订单或利润。

行业商业化成熟度差异很大：
- **成熟工业视觉**：3C、锂电、光伏、半导体、汽车产线检测，关注资本开支、设备更新、客户验收与复购。
- **精密测量与三维扫描**：工业质量检测、逆向工程、齿科数字化等，关注精度、重复性、软件工作流与渠道。
- **工业传感器**：压力、温度、位移、力/扭矩、光电、编码器等，关注可靠性、认证周期、量产成本与客户粘性。
- **机器人视觉/力觉**：潜在空间大，但应区分送样、定点、小批量和规模出货；人形机器人预期不能代替当期业绩。
- **检测软件与 AI**：关注误检/漏检、部署成本、节拍、维护费用和可复制交付，而不是只看算法演示。

## 二、产业链结构

```text
上游：光学、芯片与精密部件
├─ CMOS/图像传感器、模拟/信号处理芯片
├─ 镜头、光源、滤光片、激光器
├─ 光栅、编码器、精密机械与标定件
├─ MEMS、压力/温度/磁/光/力敏元件
└─ 工业计算平台、接口与通信组件
        ↓
中游：传感、成像、测量设备
├─ 工业相机、线扫/面阵相机、3D相机
├─ 机器视觉光源、镜头、采集卡与控制器
├─ 2D/3D视觉算法、视觉软件与边缘计算
├─ 位移/压力/温度/力矩等工业传感器
├─ 三坐标、激光跟踪、光学测量、3D扫描
└─ 在线检测、自动化检测设备与系统集成
        ↓
下游：工艺与应用场景
├─ 3C/半导体：尺寸、缺陷、晶圆/封装检测
├─ 锂电/光伏：极片、焊接、外观、尺寸检测
├─ 汽车/零部件：装配、焊缝、表面与尺寸检测
├─ 机床/机器人：定位、编码、力控、状态监测
├─ 食品/医药/物流：识别、分拣、追溯与安全检测
└─ 航空航天/精密制造：高精度测量与质量验证
```

## 三、各环节的商业化指标

| 环节 | 核心竞争力 | 重点跟踪指标 | 主要风险 |
|---|---|---|---|
| 工业相机/图像传感 | 帧率、分辨率、动态范围、稳定供货 | 出货量、ASP、毛利率、客户集中度 | 标准品价格竞争、核心芯片供应 |
| 镜头/光源/光学器件 | 成像质量、均匀性、适配与可靠性 | 产品组合、客户复购、良率、成本 | 产品同质化、下游资本开支波动 |
| 2D/3D机器视觉系统 | 算法、成像、工艺知识、整线适配 | 项目订单、验收周期、复购、售后收入 | 定制化过高、项目制回款慢 |
| 工业传感器 | 精度、漂移、寿命、抗干扰与认证 | 量产客户、良率、单位成本、回款 | 客户认证周期长、低价替代 |
| 力/扭矩与机器人感知 | 多轴标定、动态响应、耐久性 | 客户定点、送样到量产转化、出货 | 机器人放量不及预期、单机方案变化 |
| 三维扫描/精密测量 | 精度、重复性、校准与软件生态 | 设备销量、软件收入、服务收入、海外渠道 | 高端市场竞争、需求周期性 |
| 工业检测设备集成 | 工艺理解、节拍、误检漏检控制 | 新签订单、交付验收、项目毛利率 | 非标项目风险、应收与存货上升 |

## 四、市场与政策信号：从宏观数据到公司利润必须经过验证

国家统计局工业司对 2026 年 7 月工业生产数据的解读提到，规模以上工业增加值同比增长 4.5%，高技术制造业增加值增长 16.9%；产品层面传感器产量同比增长 35.3%，工业机器人产量增长 30.2%，工业控制相关设备也较快增长。这是产业需求与供给变化的宏观背景，不能直接作为任何个股的业绩预测。

2026 年半年报披露也显示机器视觉公司经营表现分化：部分企业受益于视觉与 AI 方案升级、海外拓展或高精度测量需求；另一些企业仍受传统下游资本开支、消费电子需求、原材料和费用影响。投资分析必须逐家公司验证收入来源和利润质量。

## 六、ETF 映射：不预设一定存在纯主题产品

工业传感器、机器视觉、精密测量可能分散在机器人、工业自动化、半导体、智能制造、高端装备等指数中。不能仅凭 ETF 名称就认为其能代表该产业链。

建立候选池时：
1. 查验指数编制规则与最新成分股/权重，确认视觉、传感、测量业务的实际权重。
2. 计算前十大成分集中度，并与机器人、半导体、工业自动化主题重叠比较。
3. 核验基金规模、日均成交额、买卖价差、费率、跟踪误差和折溢价。
4. 若能获得基金份额/净申赎数据，应与价格和成交额分开观察；成交额不是净流入，份额变化也要考虑拆分、合并等因素。
5. 若主题纯度和流动性不合格，允许结论为“无合适 ETF”，不要为了交易而强行映射。

## 七、每日资金、情绪与趋势信号

### 资金与交易活跃度
- 主题 ETF：成交额、份额变化、折溢价；有可靠来源时再纳入净申赎。
- 产业链个股：成交额相对 20 日均值、上涨/下跌时量价变化、核心股与跟随股的成交结构。
- 平台“主力净流入”等数值是特定算法口径，必须标记来源与算法，不视为真实可直接观测的资金流。

### 情绪与广度
- 板块上涨/下跌家数、中位数涨幅、涨停/跌停、炸板率。
- 强势是否从单一机器人概念股扩散到工业视觉、传感器、检测设备的多家公司。
- 仅少数小市值个股拉升、其余成分股走弱时，不将其解释为产业链全面走强。

### 趋势
- 个股与候选 ETF 对沪深 300、中证 1000 等基准的 5/20/60 日相对强度。
- 放量突破、回撤缩量、均线/平台变化，均需与板块广度共同观察。
- 研究信号必须保存当日可获得的数据与时间戳，禁止回测时使用未来公布的财报或事后修订数据。

## 八、场景矩阵

| 场景 | 可观察证据 | 研究结论方向 |
|---|---|---|
| 工业需求复苏且订单转化 | 订单增长、验收兑现、毛利稳定、现金流改善 | 深入验证受益环节与交易信号 |
| 产量高增但企业收入未跟上 | 公司应用敞口低、价格下降或库存增加 | 降低宏观产量数据的预测权重 |
| 机器人题材升温但量产证据弱 | 仅送样/定点、收入占比小、费用增长 | 作为预期主题观察，不视作盈利兑现 |
| 视觉方案升级但项目回款慢 | 合同增加、应收和存货上升、现金流恶化 | 警惕项目制业务质量与营运资金压力 |
| 板块趋势与广度共振 | 相对强度改善、成交活跃、上涨家数扩大 | 进入观察/验证阶段，不等于无条件买入 |
| 主题拥挤且基本面证伪 | 估值扩张、订单下滑、放量破位 | 重新检验假设，控制风险敞口 |

## 九、反证清单

- 宏观传感器产量增长，但目标公司的工业应用占比很低。
- 客户定点或送样长期不能转化为批量订单。
- 订单增长但验收延迟，应收账款、合同资产和存货持续上升。
- 营收增长依赖低毛利集成项目，毛利率和经营现金流恶化。
- 研发费用持续增加，但新产品未形成稳定复购或可规模复制的交付。
- 下游 3C、锂电、光伏等资本开支收缩，检测设备订单延后。
- 主题 ETF 持仓重叠高、成交不活跃或折溢价异常。

## 十一、统一输出格式

- **景气：** 改善 / 持平 / 转弱；列出数据来源和发布日期。
- **商业化：** 送样 / 定点 / 小批量 / 规模量产 / 稳定复购。
- **盈利传导：** 订单 → 交付验收 → 收入 → 毛利率 → 现金流，指出瓶颈。
- **市场信号：** 相对强度、成交额、情绪广度、价格趋势。
- **ETF可交易性：** 指数敞口、流动性、费用、份额变化和折溢价。
- **反证：** 至少列出两条能推翻当前判断的事实。
- **行动：** 观察 / 等待确认 / 风险降低 / 暂不交易，不用单一题材替代风险评估。
