# 01｜A 股全市场行业地图

> 本文是全市场研究工作地图，不是官方分类表，也不是当前行业涨跌排名。正式行业代码和三级目录以核验后的分类数据为准。

## 一、三个观察视角

1. **上市公司分类**：回答公司主营业务归属哪个标准行业，用于覆盖统计、公司比较和行业数据接入。
2. **产业链**：回答谁向谁供货、谁为谁付钱、瓶颈和利润在哪里，用于供需传导研究。
3. **投资主题**：如人工智能、低空经济、机器人、出海等跨行业主题，用于追踪共同催化因素。

三者分开维护，再建立映射。不能仅凭概念标签认定公司拥有显著业务敞口。

## 三、每个行业都要回答的六类问题

### 1. 需求
需求来自居民消费、企业资本开支、政府投资、出口，还是库存补库？属于刚需、可选消费、替换需求，还是新技术创造的增量需求？领先指标是什么？

### 2. 供给
产能、在建工程、资本开支、开工率如何变化？进入壁垒、技术壁垒、牌照和资源禀赋如何？供给响应需要多长时间？

### 3. 价格与库存
产品价、原料价、加工价差和库存处于什么方向？库存上升是主动补库还是被动累库？价格变化来自短缺、成本、汇率还是短期交易？

### 4. 盈利与现金流
收入、毛利率、净利率、经营现金流和资本开支如何变化？利润能否转化为现金？产业链中谁拥有议价权？

### 5. 估值与预期
当前估值隐含什么增长假设？利润是否处于周期高点或低点？股价是否已提前反映基本面改善？

### 6. 风险与反证
哪些事实会推翻当前判断？是否存在供给过剩、监管变化、客户集中、技术替代、高杠杆或海外贸易风险？

## 四、宏观变量到行业的传导

| 变量 | 可能影响方向 | 必须核实的中间环节 |
|---|---|---|
| 利率与信用条件 | 银行、地产、券商、保险、成长行业估值 | 融资成本、信用扩张、资产质量、折现率 |
| 财政与基建支出 | 建筑、建材、工程机械、电网、交通 | 资金落实、新签订单、开工、回款 |
| 居民收入与消费信心 | 食品饮料、家电、零售、旅游、医疗服务 | 客流、客单价、销量、渠道库存 |
| 出口与汇率 | 电子、机械、汽车、家电、纺织、航运 | 海外订单、汇兑、关税、海外产能 |
| 大宗商品价格 | 能源、有色、化工、钢铁、航空、制造业 | 售价与成本、库存损益、加工价差 |
| 技术迭代 | 半导体、通信、软件、机器人、汽车、医疗器械 | 性能、成本、资本开支、商业化收入 |
| 环保与能耗约束 | 能源、钢铁、化工、有色、建材 | 有效产能、停产、成本和供给集中度 |
| 人口与结构变化 | 医疗、养老、教育、食品、住房、消费服务 | 需求结构、支付能力、长期市场空间 |

这些关系不是机械的利好/利空标签。必须写清传导路径、时滞、受益环节和反例。

## 五、如何发现还未成为热点的变化

- **订单先行：**新订单、招标、合同负债、交付周期。
- **供需先行：**库存下降、交期拉长、开工率提升、产能退出。
- **价格先行：**产品价格止跌、加工价差修复、原料成本回落。
- **财务先行：**现金流改善、应收增速下降、毛利率企稳。
- **政策先行：**标准、采购规则、补贴、准入或监管发生可验证变化。
- **技术先行：**良率、成本、性能和可靠性达到商业化门槛。
- **市场确认：**相对强弱改善、成交额放大、上涨广度扩散、回撤承接增强。

单一信号不足以得出结论。尽量使用两个以上独立维度的证据，并主动记录反证。

## 六、研究优先级

先不预设哪个行业最值得买。研究优先级可参考：变化是否显著、数据是否可靠、供需是否有证据、A 股公司是否真实受益、估值是否已透支、风险是否可识别、是否有合适的指数或 ETF 观察工具。优先级只分配研究精力，不等于买入评级。

## 七、产业链覆盖优先于单行业深挖

本手册必须同时维护两张不同的地图：一张是申万层级分类下的三级行业覆盖清单，另一张是跨行业的上下游投入产出关联矩阵。行业档案只是两张地图上的节点，不得因为某一个行业专题较早建立，就把项目资源长期集中于该行业。

- 全市场产业链总表见 [全产业链上下游关联矩阵](./12-全产业链上下游关联矩阵.md)，覆盖资源能源、材料、制造、科技、消费、医药、基建、交通、金融和服务等主要经济活动。
- 建设顺序为：全市场骨架 → 31 个一级行业全景卡 → 134 个二级行业链条 → 346 个三级行业逐项覆盖 → 公司/ETF 映射 → 指标持续跟踪。分类数量对应申万 2021 版历史基准，正式使用前须复核版本。
- 每条产业链必须明确上游投入、中游转化、下游客户、最终付款方、关键指标、利润/现金流传导和反证条件；允许一个行业跨多个产业链。
- 半导体设备目前只是一个初步档案，不代表全项目的优先级或研究终点。
