# 15｜电力、电网与新能源产业链专题

> **文档定位：** 本专题把电力运营、电网建设、风电、光伏、储能与电池放在同一张产业链图中研究。重点区分“装机增长”“设备订单”“项目收益”和“上市公司利润”，它们不是同一个指标。  
> **数据截止说明：** 本文引用的行业规模数据截至对应官方来源所注明的期间；不可把不同统计时点、统计口径的数据直接拼接为同一时间序列。本文是研究框架，不是实时行情结论或买卖建议。

## 二、全链条最重要的区分

1. **装机不等于发电量。** 装机容量还要结合利用小时、天气、检修、弃风弃光和并网条件分析。
2. **发电量不等于收入，更不等于利润。** 电价、市场化交易比例、辅助服务、燃料成本、折旧、融资费用和利用率都会影响兑现。
3. **电网投资不等于所有设备公司都受益。** 必须进一步拆分电压等级、交流与直流、主网与配网、招标批次、交付周期和公司中标份额。
4. **新能源新增装机不等于设备价格上涨。** 产能过剩、竞争报价、原材料成本和技术迭代可能使装机增长与制造商利润背离。
5. **储能装机不等于储能项目有合理回报。** 需要核实调用次数、充放电价差、容量补偿、辅助服务收入、效率损耗和项目融资成本。
6. **电力系统的瓶颈会从发电侧转移到电网、调节能力和市场机制。** 随着风光占比提高，消纳、灵活性、跨区输送和系统稳定性的重要性上升。

## 三、行业卡一：电力运营与公用事业

### 业务链条

- 上游：煤炭、天然气、核燃料、水资源、风光资源、发电设备、融资与工程建设。
- 中游：火电、水电、核电、风电、光伏、生物质及综合能源运营。
- 下游：电网企业、售电主体、工业用户、商业用户和居民用电。
- 主要商业模式：发电量与结算电价形成收入，扣除燃料、运维、折旧、财务费用等后形成利润；不同电源类型成本结构差异很大。

### 重点拆分

| 类型 | 核心驱动 | 重点指标 | 常见误判 |
|---|---|---|---|
| 火电 | 电量、电价、煤价、容量与辅助服务机制 | 利用小时、入炉煤成本、度电毛利、负债、容量电费 | 只看煤价下跌，忽略电价与利用小时 |
| 水电 | 来水、发电量、结算电价、折旧和资本开支 | 来水偏差、利用小时、发电量、单位成本、现金流 | 把单年丰水期当作长期增长 |
| 核电 | 核准与建设进度、投产节奏、利用小时、资本成本 | 在建机组、投产节点、利用小时、财务费用 | 把远期规划直接当成当期利润 |
| 风光运营 | 装机、资源条件、利用小时、电价、消纳与融资 | 新增并网、利用小时、弃电率、项目收益率、负债 | 只看新增装机，忽略低利用率和资本成本 |
| 综合能源与售电 | 客户负荷、购售电价差、服务合同、交易能力 | 售电量、价差、客户续约、应收账款、现金流 | 将销售电量增长等同于利润增长 |

### 核心判断框架

- 火电企业要同时观察燃料成本和电价机制，不能简单把煤价与利润画成单向关系。
- 水电需要对照来水和多年均值；丰水、枯水会造成年度业绩波动。
- 核电与大型电源项目建设周期长，资本开支、投产时间和融资成本影响长期回报。
- 风光运营商应按项目和区域核实利用小时、并网消纳、交易电价、融资与运维成本。
- 公用事业具有一定防御属性不代表估值无风险；利率、债务、资本开支和监管变化都可能影响股东回报。

## 四、行业卡二：电网设备与电力基础设施

### 业务链条

- 上游：铜、铝、钢材、绝缘材料、电子元器件、功率半导体及专用设备。
- 中游：变压器、开关设备、输电线路、线缆、换流阀、继电保护、自动化、计量与配电设备。
- 下游：国家及地方电网、发电企业、工业园区、数据中心、轨道交通、新能源基地和海外电力项目。
- 订单兑现链条：规划与核准 → 招标 → 中标 → 排产 → 交付验收 → 收入确认 → 回款。

### 关键研究指标

| 维度 | 指标 | 为什么重要 |
|---|---|---|
| 需求 | 电网工程投资、招标金额、招标批次、项目核准与开工 | 判断行业需求是否转化为实际订单 |
| 结构 | 特高压、主网、配网、智能化、储能接入、海外项目占比 | 不同产品的竞争格局和利润率不同 |
| 公司订单 | 中标金额、在手订单、交付周期、客户集中度 | 在手订单需要结合执行节奏判断 |
| 盈利 | 毛利率、原材料成本、产品组合、产能利用率 | 收入增长不一定带来利润率改善 |
| 现金流 | 应收账款、合同资产、经营现金流、回款周期 | 工程与设备企业可能出现利润先确认、现金后回收 |
| 竞争 | 招标份额、产品认证、交付能力、海外认证 | 行业总投资增长不代表每家公司份额上升 |

### 传导关系

电网投资上升，先影响规划、招标与设备订单；随后经过排产、交付和验收，才可能反映在收入和利润中。若原材料上涨、价格竞争激烈、交付延后或回款周期拉长，订单增长仍可能无法转化为现金流改善。

**反证条件：** 招标增量低于预期、项目审批延迟、设备价格下跌、铜铝成本上涨、客户集中度过高、应收账款增速长期快于收入。

## 五、行业卡三：光伏

### 产业链与主要环节

- 上游：工业硅、硅料、硅片、电力、玻璃、胶膜、银浆、铝材。
- 中游：电池片、组件、逆变器、支架、跟踪系统及系统集成。
- 下游：集中式电站、分布式电站、工商业屋顶、户用项目、海外市场和运维服务。
- 另需关注：并网消纳、电力市场交易、储能配套、组件回收和技术路线转换。

### 不能只看新增装机

| 环节 | 优先指标 | 关键问题 |
|---|---|---|
| 硅料与硅片 | 价格、库存、开工率、有效产能、成本曲线 | 供给是否出清，新增产能何时释放 |
| 电池片与组件 | 排产、价格、库存、毛利率、技术路线 | 价格上涨是否来自需求改善，还是阶段性供给扰动 |
| 逆变器与系统设备 | 出货量、海外收入、库存、售后服务、渠道 | 终端安装、渠道库存和确认收入是否一致 |
| 电站开发运营 | 并网容量、利用小时、交易电价、项目融资 | 装机增长能否转化为稳定现金流 |
| 海外市场 | 订单、认证、贸易规则、渠道库存、回款 | 海外增量是否伴随更高成本或贸易风险 |

### 行业逻辑的双面性

光伏装机增长能扩大长期市场，但制造环节的利润取决于供需平衡、技术迭代和产能利用率。若扩产速度超过需求，行业可能出现量增价跌、库存增加和利润承压。研究时应把制造环节与电站运营分开，并区分国内与海外市场。

## 六、行业卡四：风电

### 产业链与主要环节

- 上游：钢材、铜材、树脂、玻纤、碳纤维、轴承、齿轮箱、功率器件。
- 中游：整机、叶片、塔筒、铸锻件、轴承、海缆、变流器、控制系统。
- 下游：陆上风电、海上风电、风电基地、海上送出工程和运营维护。
- 海上风电与陆上风电的施工、运输、基础、海缆、运维和项目风险不同，应分开比较。

### 关键指标

| 维度 | 指标 | 解释 |
|---|---|---|
| 需求 | 核准、招标、开工、吊装、并网容量 | 各阶段之间存在时间差 |
| 价格 | 整机中标价格、塔筒和海缆价格 | 订单规模与单价需要同时观察 |
| 成本 | 钢材、铜材、运输、施工和海上安装成本 | 原材料或施工成本变化会影响项目毛利 |
| 竞争 | 订单份额、产品可靠性、质保支出、海外认证 | 低价中标可能带来利润和质量压力 |
| 运营 | 利用小时、故障率、运维成本、弃风率 | 运营端的长期回报依赖实际发电表现 |
| 现金流 | 预付款、合同资产、应收账款、质保金 | 项目交付与回款时点可能错配 |

**反证条件：** 招标规模不及预期、整机价格竞争加剧、原材料与海上施工成本上升、项目延期、质保费用增加、海外贸易壁垒。

## 七、行业卡五：储能与电池

### 产业链

- 上游：锂、铁、磷、镍、钴、石墨、铜箔、铝箔、电解液、隔膜及其他材料。
- 中游：电芯、模组、电池簇、功率转换系统、温控、消防、能量管理和系统集成。
- 下游：电源侧、电网侧、工商业用户侧、家庭储能、通信备电和其他专用场景。
- 相关环节存在交叉，但动力电池、储能电池和消费电池的客户、规格、寿命、安全要求与盈利逻辑不能简单等同。

### 储能项目的经济性核验

1. 收入来自哪里：峰谷价差、容量补偿、辅助服务、合同能源管理或其他结算机制？
2. 一年预计运行多少次，实际调用率如何，充放电效率损耗多少？
3. 电芯衰减、循环寿命、温控、消防和维护成本是否纳入测算？
4. 并网、场地、融资、保险和电力交易费用是否完整计入？
5. 收益机制是已执行的结算规则，还是规划、试点或预期？
6. 项目是否存在利用率低、收益来源单一或过度依赖补贴的问题？

### 关键指标

| 维度 | 指标 | 误判风险 |
|---|---|---|
| 需求 | 项目备案、招标、中标、实际投运、调用次数 | 备案容量不等于已投运容量 |
| 制造 | 电芯价格、系统价格、产能利用率、库存、毛利率 | 出货量增长可能伴随降价和利润下滑 |
| 原料 | 锂盐等材料价格、库存、加工费 | 原料降价可能伴随产品售价更快下跌 |
| 技术 | 循环寿命、安全性、能量密度、系统效率 | 实验室参数不等于实际项目表现 |
| 项目回报 | 实际结算收入、利用率、衰减、融资成本 | 预测收益率不能代替运行数据 |
| 现金流 | 应收账款、合同资产、经营现金流、质保责任 | 系统集成商可能承担交付与回款压力 |

## 八、跨行业传导矩阵

| 变化起点 | 可能受益的环节 | 可能承压的环节 | 必须验证 |
|---|---|---|---|
| 电网投资加速 | 对应招标产品、产能与交付能力匹配的设备企业 | 未中标企业、低毛利竞标者、回款较慢的供应商 | 招标公告、中标份额、交付、毛利与回款 |
| 风光装机增长 | 具备成本、质量和交付优势的设备与运营商 | 产能过剩、价格竞争激烈的制造环节 | 装机、招标价、库存、开工率、项目收益 |
| 铜铝等原料上涨 | 资源端供应商可能受益 | 电缆、变压器及部分设备制造商可能承压 | 原料采购周期、调价条款、产品售价 |
| 电池材料降价 | 电芯与系统采购成本可能下降 | 高成本库存或高价采购企业可能承受减值压力 | 库存成本、销售价格、合同条款、减值 |
| 电力现货与辅助服务机制变化 | 灵活调节、储能及交易能力较强的主体可能受益 | 不能适应结算规则或缺少调节能力的主体 | 正式规则、实际结算、调用频次、成本 |
| 利率上升 | 低负债、现金流稳定主体相对更有韧性 | 资本密集、建设周期长、融资依赖高的项目 | 有息负债、融资利率、项目内部收益率 |

## 十、公司与交易型开放式指数基金映射规范

暂不直接把公司或基金列为推荐标的。建立映射时逐项核验：

- 公司年报、公告和主营业务构成是否支持对应产业链归属。
- 公司处于运营、设备制造、零部件、材料还是项目开发环节。
- 在手订单、产能、市场份额、毛利率、现金流和负债是否支持盈利兑现。
- 指数编制规则、成分股、权重日期和行业集中度是否与研究主题一致。
- 基金规模、成交额、费用、跟踪误差和流动性需注明数据日期。
- 行业景气、公司质量、估值与市场预期分别评价，不能相互替代。
