## 研究目标

- 了解 A 股全行业的业务模式、上下游、需求来源和竞争格局。
- 理解宏观经济、政策、技术、价格、订单和库存如何传导至行业盈利。
- 统一比较行业景气、市场表现、估值和风险。
- 找到值得进一步验证的行业变化，而不是只追逐涨幅榜。
- 研究行业时，进一步核实相关上市公司的真实业务敞口和 ETF 跟踪范围。

## 基本原则

1. **先覆盖，再筛选。** 不只研究热门科技行业，周期、消费、医药、金融、公用事业和服务业同样纳入。
2. **分类与产业链分开。** 公司行业分类、上下游关系、市场投资主题是不同维度。
3. **事实、判断、假设分开。** 关键事实注明来源、发布日期、数据期间与口径。
4. **政策不等于业绩。** 必须验证资金落地、订单、交付和财务兑现。
5. **行业好不等于股票便宜。** 还要分析估值、预期和下行风险。
6. **防止未来数据泄漏。** 历史研究只能使用目标时点已经公开且可获得的数据。
7. **不作确定性收益承诺。** 本手册用于学习与研究，不保证投资结果。

## 本手册只交付 Markdown

本项目定位为可阅读的研究手册，不开发代码、不接 API、不建数据库。研究结果直接整理成 Markdown 文档，必要时使用表格、Mermaid 流程图、产业链图和有来源的图片。未来可将 Markdown 汇编为 PDF。

## 图表与图片规范

- **流程与决策路径**：优先使用 Mermaid，便于阅读和后续修改。
- **产业链、上下游关系、宏观传导路径**：使用 Mermaid flowchart 或自制 SVG/PNG 图。
- **行业比较、景气指标、公司/ETF 对照**：优先使用 Markdown 表格；确有必要时再画图。
- **外部图片**：标注来源、发布日期（如适用）和授权/使用注意事项；不使用来历不明的图片。
- **图片文件**：统一放在 `docs/industry-research/assets/`，使用相对路径引用。
- **图表证据**：注明数据口径、截止日期；示意图明确标注“示意图”，不把假设关系画成已证实事实。

## 分类口径

申万行业体系作为研究目录的主要参考，但 2021 版清单只是历史基准，不能自动视为最新版本。国家统计局《国民经济行业分类》、三次产业划分、申万分类、产业链主题和市场概念不是同一套体系，不强行一一对应。公司实际业务应结合公开披露单独研究。

## 每个行业的最低交付要求

- 定义、业务边界、商业模式
- 上游投入、中游环节、下游客户
- 需求、供给、价格、库存、产能、订单和利润指标
- 宏观变量与政策传导路径
- 相关上市公司、真实业务敞口和 ETF 范围
- 当前事实、分析判断、待验证假设
- 看多/基准/看空情景、风险与逻辑失效条件
- 来源、发布日期、统计口径、数据截止日期和复核日期
