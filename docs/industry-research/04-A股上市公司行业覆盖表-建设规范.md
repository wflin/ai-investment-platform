# A股上市公司行业覆盖表：建设规范与底表模板

> 状态：建设规范与空白模板，**不是已完成的全量公司映射数据**。
> 目的：将行业分类连接到真实 A 股上市公司，为产业链、景气、财务和 ETF 研究提供可追溯入口。
> 版本基准：2026-10-11；当前暂以仓库中的申万 2021 版分类快照作为参照，尚需核验最新有效分类。
> 数据纪律：没有可验证来源的字段保持空白或标记“待核验”，不推测、不补造。

## 1. 三种不同的映射

| 映射层 | 回答的问题 | 主要依据 | 不应混淆的内容 |
|---|---|---|---|
| 行业分类 | 数据源把公司归到哪个行业？ | 股票代码、行业代码、分类版本 | 不代表公司所有业务都属于该行业 |
| 真实业务敞口 | 公司实际靠哪些业务赚钱？ | 年报、半年报、公告中的分部收入/利润 | 不能只凭公司名称或市场概念判断 |
| 产业链与投资主题 | 公司位于哪个环节、受什么主题影响？ | 产品、客户、供应商、收入结构及证据 | 产业链和投资主题不是官方行业分类 |

一家公司可有一个基准行业分类、多个业务敞口和多个产业链标签。以上关系应分字段记录，不能强行压成一个标签。

## 2. 覆盖范围与统计口径

- **市场范围**：默认目标为沪市、深市、北交所全部 A 股普通股；排除基金、债券、B 股及其他非 A 股普通股证券。
- **状态范围**：正常上市、停牌、风险警示等分别标记；当前上市公司统计不得混入已退市公司。
- **日期口径**：每次快照记录 as_of_date，证券清单、上市状态和行业归属对应同一截止日期。
- **分类口径**：记录分类体系、版本、生效日期和数据源。申万 2021 版只是历史基准，不自动视为 2026 年最新版本。
- **复核口径**：行业分类以明确的数据源为准；真实业务敞口优先核对最新已公开定期报告及重大业务公告。

## 3. 建议底表字段

建议最终以 CSV 或数据库维护机器可读底表，再自动生成 Markdown 汇总，避免人工维护两套相互矛盾的数据。

| 字段 | 必填 | 含义与规则 |
|---|---|---|
| as_of_date | 是 | 快照日期，YYYY-MM-DD |
| stock_code | 是 | 标准化证券代码，保留前导零 |
| stock_name | 是 | 截止日期对应的证券简称 |
| exchange | 是 | SSE / SZSE / BSE |
| listing_status | 是 | 上市、停牌、风险警示等明确状态 |
| sw_version | 是 | 申万分类版本；未确认填“待核验” |
| sw_l1_code / sw_l1_name | 是 | 申万一级代码与名称 |
| sw_l2_code / sw_l2_name | 是 | 申万二级代码与名称 |
| sw_l3_code / sw_l3_name | 视数据源 | 申万三级代码与名称；无此层级时说明原因 |
| classification_source | 是 | 分类数据源名称及链接/接口标识 |
| classification_date | 是 | 分类数据的生效日或数据源日期 |
| business_exposure | 建议 | 真实业务摘要，须可追溯到公开披露 |
| revenue_segments | 建议 | 主要业务分部及收入占比；无可靠数据则留空 |
| value_chain_tags | 建议 | 上游/中游/下游/平台/综合等，可多值 |
| theme_tags | 可选 | AI、国产替代、出海等主题，不替代行业分类 |
| evidence_url / evidence_date | 是 | 关键映射证据及发布日期/数据日期 |
| mapping_confidence | 是 | 高 / 中 / 低，并按下文规则解释 |
| review_status | 是 | 未核验 / 自动匹配待复核 / 已复核 / 存疑 |
| review_note | 可选 | 异常、跨行业经营或分类变更原因 |

## 4. 映射置信度规则

- **高**：分类代码来自可追溯的数据源，代码、名称、日期一致；业务描述有定期报告或公告支持。
- **中**：分类来自可信数据接口，但版本/生效日期尚未完全确认，或业务敞口仅有部分证据。
- **低**：仅根据公司名称、市场概念、新闻标题或非权威二手资料推断。
- 置信度不是投资评级，也不代表盈利质量。

## 5. 覆盖率与质量检查

覆盖率必须以同一日期、同一市场范围的 A 股普通股清单作为分母。不得用行业分类条目数、指数成分股数或 ETF 持仓数代替上市公司总数。

1. **证券主键唯一**：同一快照下 stock_code 不重复。
2. **市场范围完整**：公司清单与基准证券清单做双向差集，输出缺失和多余代码。
3. **分类代码有效**：行业代码必须存在于同版本分类字典；失效或改名代码单独列出。
4. **层级一致**：三级行业必须归属正确的二级、一级行业。
5. **空值可解释**：无分类、转板或分类暂缺等情况必须有状态和备注。
6. **状态口径一致**：当前统计排除已退市公司，历史快照保留当时状态。
7. **业务证据可追溯**：跨行业公司、主营变化公司和分类变更公司进入人工复核队列。
8. **时间防泄漏**：历史回测只能使用当时已公开的分类、公司状态和财报，禁止把后来的数据回填到过去。

### 核心统计指标

| 指标 | 计算方式 |
|---|---|
| 基准证券数 | 截止日期符合范围的 A 股普通股数量 |
| 已匹配数 | 能匹配到有效行业分类的证券数 |
| 分类覆盖率 | 已匹配数 / 基准证券数 |
| 待复核比例 | 待复核证券数 / 基准证券数 |
| 未匹配列表 | 基准清单中没有有效分类映射的证券 |
| 孤立映射列表 | 映射表中不在基准证券清单内的证券 |
| 业务证据覆盖率 | 有可核验业务证据的证券数 / 已匹配证券数 |

所有覆盖率同时展示分子、分母、截止日期和数据源，不能只报百分比。

## 7. 数据来源优先级

### 已找到的官方参考入口（2026-10-11 检查）

- **上交所上市公司地区/行业分类列表**：https://www.sse.com.cn/assortment/stock/areatrade/trade/ 。页面展示中国上市公司协会行业分类及行业股票列表，检索时页面显示分类数据日期为 2026-10-09。可作为核对沪市公司证券清单、行业分类和股票列表的官方入口。
- **上交所行业分类说明**：https://www.sse.com.cn/market/stockdata/price/sh/ 。其说明采用中国上市公司协会《上市公司行业统计分类指引》，并提示分类结果以中国上市公司协会公布为准。
- **证监会《上市公司行业分类指引》（2012 年修订）**：https://www.csrc.gov.cn/csrc/c101864/c1024632/content.shtml 。这是监管分类标准的参考来源，不等同于申万行业体系。

**重要区别**：以上官方入口采用的行业分类体系不是申万行业分类。可用来交叉核对证券清单和官方行业口径，但不能直接填入申万一级/二级/三级字段。要完成申万映射，仍须取得可核验版本的申万分类与证券映射数据，并记录版本、生效日期和授权条件。

1. 交易所及官方披露平台：核对证券代码、上市状态、公告和定期报告。
2. 可明确版本和日期的行业分类数据源：建立行业代码映射，并保留原始文件/接口标识。
3. 公司年报、半年报及重大公告：判断实际业务敞口和收入分部。
4. 商业数据终端或公开金融数据接口：可用于批量整理，但必须记录来源、更新时间、许可条件，并抽样与官方披露交叉核验。
5. 新闻、研报和市场概念标签：只能作为发现线索，不能单独作为最终分类证据。

不得假定某个接口免费、完整、可商用或提供最新申万分类；接入前应核实字段、授权和更新频率。

## 8. 建议落地流程

固定市场范围与截止日期 → 取得 A 股普通股基准清单 → 取得带版本的行业分类映射 → 按证券代码合并 → 检查缺失、重复、无效代码 → 生成覆盖率与异常清单 → 补充年报业务敞口证据 → 人工复核跨行业与分类变更公司 → 生成 Markdown 汇总和变更记录 → 按更新周期重新核对。

## 9. 与现有平台衔接

- 先盘点现有行业分类、个股列表和行业评分的数据模型/API，优先复用，不重复建设平行事实表。
- 本文件只定义研究层字段、核验规则和展示模板；没有证据表明已存在的接口或字段，不假定其具体名称。
- 若系统已提供股票代码、行业代码和分类版本，应将其作为候选输入，并补充数据日期、来源和核验状态。
- 真正落地全量映射前，先输出数据源盘点报告，确认接口可用、覆盖范围、分类版本和授权限制。
- 本阶段不修改业务代码，不生成虚构公司清单或覆盖率。
