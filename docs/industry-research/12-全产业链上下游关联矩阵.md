# 12｜A股全产业链上下游关联矩阵

> 目标：先建立跨行业的宽覆盖骨架，再逐步用可核验资料填充细分环节、上市公司、指标和 ETF。  
> 版本：v0.1｜建立日期：2026-10-11  
> 边界：本表是研究用产业关系地图，不是官方行业分类，也不是已验证的逐家公司供应链数据库。箭头表示常见需求/供给关系，不能推定所有公司都有直接交易关系。

## 一、使用规则

1. **宽度优先：** 先覆盖资源、能源、材料、制造、科技、消费、医疗、地产基建、交通物流、金融和服务，再向细分行业下钻。
2. **标准分类与产业链分开：** 申万三级行业用于统计归类；产业链用于描述投入产出、付款方、供货方、替代关系和利润传导；投资主题另行映射。
3. **上下游不等于股价联动：** 上游涨价可能利好资源供应商、却压缩下游毛利；需求增长也可能被扩产、竞争、价格战或回款拖累抵消。
4. **公司映射要有证据：** 优先使用年报主营业务、分部收入、客户/供应商披露、公告、招投标与产品认证。概念标签不能代替收入敞口证据。
5. **指标要写口径：** 每个指标记录来源、发布日期、数据期间、单位、频率和修订情况；没有数据就标“待核验”，不猜数。
6. **研究状态分级：** 本文列出的链条是“概念骨架”，不算行业专题已完成；只有证据、指标、公司映射与反证达到标准，才更新进度表。

## 三、每条链必须补齐的关系

每条产业链逐步扩充为以下结构，而不是只列“上游/中游/下游”名称：

| 关系字段 | 必须回答的问题 | 可接受证据 |
|---|---|---|
| 最终需求 | 谁最终付钱？消费、投资、出口还是政府采购？ | 统计数据、客户披露、订单和采购公告 |
| 上游投入 | 核心原料、零部件、能源、软件和服务是什么？ | 年报成本说明、采购披露、产品资料 |
| 中游转化 | 哪些加工、制造、集成或运营环节创造价值？ | 产品线、分部收入、产能和工艺资料 |
| 下游客户 | 客户行业、终端用途、替代方案是什么？ | 客户/供应商披露、招投标、认证公告 |
| 议价权 | 价格由谁决定？切换供应商成本多高？ | 价格、毛利率、合同模式、客户集中度 |
| 周期位置 | 供给紧张、平衡、过剩还是去库存？ | 库存、产能、价格、订单、开工率 |
| 利润与现金流 | 收入增长能否转成利润和现金？ | 财报、现金流、应收、存货、资本开支 |
| A股映射 | 哪些公司是核心供应商、替代供应商、终端客户？ | 最新年报和公告，按业务敞口分层 |
| ETF映射 | 哪些指数覆盖链条的哪些环节？是否跨链？ | 指数编制方案、基金合同、定期报告、PCF |
| 反证与风险 | 什么情况会使链条判断失效？ | 竞争、扩产、技术替代、政策、贸易和回款风险 |

## 四、跨链传导示例

### 示例 A：AI 数据中心扩张

AI 应用付费/云需求 → 云厂商资本开支 → 服务器与加速器 → 半导体设计制造/封装 → 半导体设备材料；同时传导到光模块、交换机、光纤、供配电、变压器、散热、IDC 与发电运营。

**不能直接推导：** 算力投资增长不等于所有相关公司利润增长。需检查订单归属、产能、客户集中、产品迭代、资本开支回报和估值预期。

### 示例 B：电动车与储能

终端销量/储能招标 → 电池排产 → 正负极/电解液/隔膜 → 锂镍钴与石墨 → 设备、自动化、电力与回收。

**不能直接推导：** 锂价上涨可能利好部分资源企业，却压缩电池和材料环节利润；扩产过快会导致加工费和售价下降。

### 示例 C：地产与基建

销售与项目资金 → 新开工/施工/城市更新 → 钢铁、水泥、玻璃、防水管材 → 工程机械、建筑施工、设计咨询 → 家居、家电、物业与消费服务。

**不能直接推导：** 政策表态和计划投资不等于实物工作量、企业收入或现金回款。

### 示例 D：农业与食品

天气/种植面积 → 粮食与饲料价格 → 养殖成本/出栏 → 屠宰加工与食品制造 → 批发零售与餐饮终端。

**不能直接推导：** 农产品涨价不一定利好所有农业公司；要区分种植、养殖、饲料、加工与品牌环节的成本和售价变化。

### 示例 E：医药创新与医疗支付

研发管线 → 临床试验/CRO → 注册审批 → 生产与商业化 → 医院/药店 → 医保、商保和患者支付。

**不能直接推导：** 临床进展不等于获批，获批不等于进入医保，进入医保也不保证销量和利润。

## 五、从宽到深的建设顺序

### 阶段 1：全市场宽覆盖

- 建立 31 个一级行业、134 个二级行业、346 个三级行业的分类索引（这是申万 2021 版历史基准，正式使用前须复核分类版本）。
- 将三级行业挂接到本矩阵的一条或多条产业链；允许跨链，不强行一对一。
- 每个一级行业先完成一页全景卡：需求、供给、周期、核心指标、上下游、主要风险、相关公司/ETF待核验项。

### 阶段 2：上下游连接与覆盖检查

- 对每条链画出投入品、设备、生产/运营、渠道、最终需求和资金流。
- 建立“上游行业—中游行业—下游行业”关联表，并标注关系类型：直接投入、资本开支、替代关系、共同需求或政策传导。
- 标出尚无可靠上市公司映射、缺少公开指标或没有合适 ETF 的空白区域；空白是待研究项，不是遗漏后默认为不存在。

### 阶段 3：景气跟踪与横向比较

- 对周期、先进制造、科技、消费、医药、金融地产、公用事业等不同商业模式使用可比的指标组，不用同一指标机械套所有行业。
- 统一记录指标方向、频率、数据截止日期、来源、滞后期和反证。
- 区分行业基本面改善、股价已反映预期、估值位置和交易流动性，避免把“好行业”直接等同于“好买点”。

### 阶段 4：公司与 ETF 映射

- 公司按“核心敞口/重要敞口/间接受益/概念关联待证”分层；没有分部数据时明确说明。
- ETF 按指数覆盖、成分股、权重集中度、规模、成交额、折溢价、费用和跟踪误差比较。
- 不用 ETF 名称代替实际持仓，不把每日申赎清单等同于完整实时权重。
