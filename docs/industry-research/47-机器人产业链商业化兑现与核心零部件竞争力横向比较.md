# 机器人产业链商业化兑现与核心零部件竞争力横向比较

> 研究期次：第47期｜更新日期：2026-10-12  
> 研究对象：A股机器人产业链上市公司及相关业务；本报告为产业研究，不构成买卖建议。  
> 方法：将“公司传统主业”“机器人相关产品”“人形机器人新增业务”分开，避免把概念关联、订单、出货和利润混为一谈。

## 一、结论先行

**本轮横向比较的核心结论：当前最有用的筛选维度不是“谁最像人形机器人概念股”，而是“谁有可核验的批量交付、谁有明确收入贡献、谁的盈利和现金流同步改善”。**

2026年9月发布的行业综述援引176家核心产业链样本统计，样本公司2026年上半年营收同比增长13.79%，归母净利润同比增长1.52%；报告判断当前业绩仍主要由传统主业驱动。这意味着产业链整体增长和人形机器人新业务兑现是两个不同问题。

公开披露中存在更明确的商业化例子：
- 东方精工披露，相关人形机器人业务上半年签约订单约8300万元，确认营业收入2666万元，并实现批量交付。订单金额与确认收入存在差异，后续需跟踪交付、验收、回款及业务持续性。
- 雷赛智能相关半年报点评披露，无框力矩电机在手订单超过100万台，行星关节模组、谐波关节模组及高自由度灵巧手已实现批量供应。需要继续核实订单口径、取消/延期风险、实际收入和回款。
- 柯力传感半年报披露，上半年机器人力学传感器销售超过2000只，4月以来月订单持续突破千只；部分客户批量订货，部分头部客户仍处于验证阶段。
- 汇川技术半年报列出无框力矩电机、低压直流驱动器、行星滚柱丝杠、编码器、旋转/直线执行器和仿生臂等产品，但产品布局本身并不能证明相关业务已形成显著利润。

## 二、统一商业化阶段尺

| 阶段 | 可接受的证据 | 不应误读为 |
|---|---|---|
| S0 概念/规划 | 路演、新闻、战略布局 | 客户订单或商业化 |
| S1 研发/送样 | 样品交付、实验室验证 | 客户定点或量产 |
| S2 客户验证/定点 | 客户认证、定点公告、具体项目 | 大批量供货 |
| S3 小批量 | 有明确小批量交付或试产 | 规模收入、稳定盈利 |
| S4 批量交付 | 可核验出货/批量供货，最好有客户或数量信息 | 业务利润已经显著 |
| S5 财务兑现 | 机器人相关收入可识别，利润质量和现金回款支持增长 | 估值必然合理或股价必然上涨 |

**评级要落到具体产品和具体业务，不要给整家公司贴统一标签。** 一家公司在工业自动化主业可能已经达到S5，但其人形机器人新产品仍可能处于S1或S2。

## 三、公司与环节横向比较

| 公司/样本 | 产业链位置 | 公开证据与阶段判断 | 需要重点核验的下一步 |
|---|---|---|---|
| 东方精工（002611） | 人形机器人本体生产组装、自动化产线 | 公司披露上半年签约订单约8300万元、确认收入2666万元并批量交付；相关业务具备收入线索，按公开披露可观察S4及初步财务兑现 | 订单客户集中度、关联交易/项目来源、收入毛利、回款、后续独立客户复购 |
| 雷赛智能（002979） | 无框力矩电机、关节模组、灵巧手、运动控制 | 券商半年报点评披露无框力矩电机在手订单超100万台，多类关节/灵巧手产品批量供应；部分产品可观察S4 | 原始公告口径、订单是否可取消、机器人业务收入占比、库存和应收变化 |
| 柯力传感（603662） | 六维力/力矩、关节力矩等传感器 | 公司半年报披露上半年机器人力学传感器销售超2000只，部分客户批量订单，多家头部客户仍验证；具体产品进入批量供货阶段 | 新业务收入/毛利、客户集中度、送样转化率、回款与复购 |
| 汇川技术（300124） | 驱动、运动控制、无框电机、丝杠及执行器 | 半年报列出多类人形机器人零部件；产品布局证据明确，但不能由此推断新业务收入规模 | 人形机器人相关收入是否单独披露、客户定点、量产、业务利润率 |
| 双林股份（300100） | 行星滚柱丝杠、微型滚珠丝杠、线性关节 | 半年报相关报道披露机器人丝杠/关节研发和产业化推进；公开证据需区分定点、小批量与规模收入 | 良率、产能利用率、折旧、订单验收、现金流 |
| 维宏股份（300508） | 灵巧手关节电机/模组、运动控制 | 公开报道披露灵巧手关节电机/模组出货量；出货是积极线索，但需核对财报收入和利润贡献 | 出货口径、产品平均售价、客户集中度、毛利率和售后成本 |
| 绿的谐波（688017） | 谐波减速器、精密传动 | 精密传动技术和制造能力可作为机器人核心部件研究样本；人形机器人业务敞口需独立验证 | 具体客户、量产份额、机器人新业务收入占比 |
| 中大力德（002896） | 减速器、电机、机电一体化 | 具备相关部件业务基础，不能将全部减速器收入视为人形机器人收入 | 产品路线、客户认证、产品单价、毛利率及真实应用 |
| 拓斯达（300607）/机器人（300024） | 工业机器人、自动化系统集成与本体 | 具备机器人或系统集成业务基础，需把成熟工业应用与人形机器人业务拆分 | 可重复场景、独立客户复购、项目毛利率、应收与合同资产 |

**重要限制：** 本表将公司披露、媒体报道和券商点评分开看待。涉及订单或出货数字时，应回到上市公司原始公告核对口径；未公开披露的机器人收入占比、单品利润率和客户身份不作推算。

## 四、跨环节竞争力比较

### 1. 减速器与精密传动
竞争力来源包括加工工艺、精度一致性、寿命、良率、成本和客户认证周期。工业机器人既有业务可以支撑制造经验，但人形机器人关节的尺寸、负载、冲击和成本约束可能不同。重点关注批量稳定性与客户扩展，而非只看技术参数或扩产计划。

### 2. 伺服、驱动与运动控制
核心指标是响应速度、低压供电适配、控制算法、散热、体积、效率和系统协同。已有工业自动化客户和规模制造能力是优势，但不能直接推出人形机器人产品已经定点或形成利润。

### 3. 丝杠与线性执行器
这类产品需要精密加工、材料/热处理、装配、润滑、耐久测试和一致性控制。扩产可能意味着公司看好需求，也可能带来折旧、库存和现金流压力。观察顺序应为客户验证—小批量—良率爬坡—交付验收—收入毛利—回款。

### 4. 力觉、触觉和运动反馈
传感器价值取决于测量精度、漂移、带宽、抗冲击、标定效率、可靠性和整机融合。送样客户多不等于批量客户多；送样转化率和批量复购比累计送样家数更有意义。

### 5. 灵巧手与微型驱动
灵巧手涉及电机、减速/传动、触觉、控制、结构与软件协同，路线仍可能变化。需要跟踪单手成本、寿命、抓取成功率、维修频率、量产良率与客户采用的方案。自由度和理论单机价值量不能代替客户采购证据。

### 6. 整机与系统集成
整机订单是需求入口，但需区分政府/园区项目、数据采集训练项目、研发试制和独立客户的生产性采购。重点验证机器人是否持续完成真实任务，是否减少人工成本、提高产能或产生可核算服务收入。

## 五、财务质量：建立统一检查表

每家公司至少记录以下指标，并按季度更新：

- **收入：** 总营收同比/环比、机器人相关收入是否单列、客户和产品口径是否稳定。
- **盈利：** 毛利率、扣非净利润、研发费用、股份支付、折旧与产能爬坡成本。
- **营运资本：** 应收账款、合同资产、存货、合同负债及周转天数。
- **现金流：** 经营活动现金流、净利润与经营现金流差异、客户预付款、回款周期。
- **资本开支：** 在建工程、固定资产增加、募投项目进度、产能利用率。
- **客户结构：** 前五大客户占比、客户是否独立、是否存在关联方或一次性项目。
- **复购质量：** 同一客户连续采购、产品进入下一代机型、从单一零件扩展到总成。

不要用单一季度现金流判断长期质量，也不要把一次性公允价值变动、政府补助或股份支付影响与主业盈利混为一谈。

## 六、ETF映射与A股观察框架

本期不猜测ETF代码，也不因基金名称中含“机器人”就认定其纯度高。对候选ETF逐只记录：
1. 最新指数名称、编制方案、成分股和权重日期；
2. 前十大持仓里有多少是直接相关业务，多少是大型综合公司；
3. 相关公司的机器人业务证据等级，以及机器人业务在上市公司中的占比；
4. ETF规模、日均成交额、跟踪误差、折溢价和费率；
5. 历史回测是否使用当时已公开的成分股，避免未来数据泄漏。

板块交易信号与基本面分开：相对强度、上涨家数占比、成交额、核心股趋势和ETF流动性可用于观察市场行为，但不能替代商业化证据。行业前景看好不代表当前估值便宜，也不意味着短期价格必然上涨。

## 七、反证与风险清单

1. 大量送样、签约或合作新闻持续出现，但收入确认和回款没有跟进。
2. 机器人相关收入增长，却依赖单一客户、关联交易或一次性项目，独立市场需求不足。
3. 批量交付增长但毛利率下降，说明价格竞争、良率或售后成本可能侵蚀利润。
4. 应收、合同资产、存货增长快于收入，经营现金流持续弱于利润。
5. 扩产快于订单兑现，固定资产折旧和营运资本占用上升。
6. 整机厂频繁更换技术路线，原有零部件定点失去价值。
7. 传统主业增长被误当作人形机器人新业务兑现，估值提前计入多年远期利润。
8. 产业故事成立但估值过高，未来业绩即使增长也可能无法满足市场预期。

## 八、下一步研究优先级

**第一优先级：** 东方精工、雷赛智能、柯力传感——公开披露中已有较具体的订单、出货或收入线索，适合跟踪后续财务兑现。

**第二优先级：** 汇川技术、双林股份、维宏股份——重点核验产品路线、客户认证、量产进度及新业务收入贡献。

**第三优先级：** 绿的谐波、中大力德、拓斯达、机器人等——按具体产品和业务证据更新等级，避免把成熟主业与人形机器人增量混为一谈。

这只是信息核验顺序，不是股票推荐或收益排序。最终判断必须结合最新公告、估值、风险承受能力和组合约束。
