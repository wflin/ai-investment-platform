# 14｜资源与基础材料产业链专题：首批五个行业

> **文档定位：** 这是全市场行业研究的第一批细化卡片，覆盖煤炭、石油石化、有色金属、钢铁、基础化工。重点是把上下游关系、价格传导和验证指标串起来，不是当前行情判断，也不是买卖建议。  
> **资料口径：** 本文先建立研究框架。涉及当前价格、库存、产量、盈利和公司业务的判断，必须在正式下结论前补充最新原始数据、发布日期、统计期间与口径。

## 一、五个行业之间的关系图

~~~mermaid

    A --> B["煤炭：动力煤、炼焦煤"]
    A --> C["石油石化：原油、天然气、炼化"]

    I --> J["电网、电池、汽车、电子、机械、建筑"]

    B --> K["电力、建材、钢铁、化工等能源用户"]
    C --> K
    J --> L["终端需求：基建、制造业、房地产、消费、出口"]
    L --> A
~~~

**如何理解这张图：**

- 煤炭和石油石化既是资源行业，也是其他行业的重要能源或原料来源；价格上涨可能改善部分资源企业收入，却会抬高下游成本。
- 有色金属的表现高度依赖具体金属，铜、铝、黄金、锂和稀土不能简单合并成一个供需逻辑。
- 钢铁、基础化工通常既受原料成本影响，也受终端需求和新增产能影响；原料涨价不一定能顺利传导到产品售价。
- 五个行业之间存在多条双向链路。判断影响时必须明确具体产品、企业所处环节、合同定价方式和库存周期。

## 二、五个行业的全景卡

### 1. 煤炭

**行业边界与链条**

- 上游投入：矿权与资源禀赋、采掘设备、人工、电力、安全环保投入和运输。
- 中游环节：煤炭开采、洗选、配煤及煤炭贸易。
- 下游需求：火力发电、钢铁焦化、建材、化工及其他工业用户。
- 主要差异：动力煤主要观察电力和工业燃料需求；炼焦煤主要观察钢铁生产与焦化链条。二者不可混用单一价格指标。

**最重要的传导问题**

- 需求端：电厂日耗、库存、天气、工业用电、钢铁产量和化工开工。
- 供给端：产量、进口、矿井安监、运输瓶颈、产能释放和库存位置。
- 盈利端：煤价变化要与单位成本、长协比例、销量、运费和资本开支共同分析。
- 下游影响：煤价上涨可能提升部分煤企利润，但会压缩火电、部分化工和建材企业的利润空间；具体影响取决于电价、合同和成本传导机制。

**首轮观察指标**

| 维度 | 优先指标 | 需要防止的误判 |
|---|---|---|
| 需求 | 电厂日耗、火电发电量、钢铁产量、化工开工 | 天气导致的短期波动不一定代表长期需求变化 |
| 供给 | 原煤产量、进口量、产能释放、运输情况 | 名义产能不等于可立即供应的有效产能 |
| 库存 | 电厂库存、港口库存、重点区域库存 | 不同地区、煤种和统计口径不可直接混比 |
| 价格 | 动力煤、炼焦煤、焦炭价格及价差 | 现货价不等于企业全部销售实现价格 |
| 公司兑现 | 单位成本、销量、长协比例、经营现金流 | 高煤价若伴随销量下降或成本上升，利润增幅可能有限 |

**反证与风险：** 需求走弱、供给快速释放、进口增加、价格监管、运输变化或安全环保成本上升，都可能使单纯依据煤价作出的判断失效。

### 2. 石油石化

**行业边界与链条**

- 上游：原油和天然气勘探开发、油田服务、工程与设备。
- 中游：原油加工、炼化一体化、基础石化原料和化工品生产。
- 下游：成品油、塑料、合成纤维、橡胶、化工材料、交通运输和制造业。
- 必须拆分：油气开采、油服、炼油、化工、贸易业务的盈利驱动并不相同。

**最重要的传导问题**

- 原油涨价对上游资源生产者可能有利，但对炼油企业未必有利；炼化利润取决于成品油和化工品售价能否覆盖原料成本。
- 需求、原油库存、炼厂开工、运输与地缘风险共同影响价格；不能只观察单一国际油价。
- 汇率、采购周期、库存计价和长短期合同会造成财报利润与现货价格走势不同步。

**首轮观察指标**

| 维度 | 优先指标 | 需要防止的误判 |
|---|---|---|
| 上游供需 | 原油产量、天然气产量、全球库存、主要产油地区供应变化 | 产量公告不等于可出口供应量 |
| 炼化 | 炼厂开工率、成品油需求、炼油价差、主要化工品价差 | 原油涨跌不能替代炼化利润指标 |
| 库存 | 原油、成品油和主要化工品库存 | 库存覆盖天数与库存绝对量含义不同 |
| 公司兑现 | 油气产量、单位成本、资本开支、分部利润、现金流 | 综合企业各业务板块可能互相抵消 |
| 外部变量 | 汇率、运费、贸易限制、供应中断 | 突发事件可能造成短期价格剧烈波动 |

**反证与风险：** 全球需求下滑、供应恢复、炼化产能过剩、产品价差收窄、贸易限制和高资本开支，都可能削弱行业利润。

### 3. 有色金属

**行业边界与链条**

- 上游：矿山勘探、采矿、选矿、回收料和矿产贸易。
- 中游：冶炼、精炼、合金、金属加工及材料制造。
- 下游：电网、电池、汽车、电子、机械、建筑、航空航天及投资需求。
- 研究必须按金属拆分：铜、铝、铅锌、黄金、白银、稀土、钨、钼、锂、镍、钴等的供需机制差异很大。

**不同金属要看不同的核心逻辑**

| 金属或类别 | 主要需求线索 | 主要供给线索 | 关键观察点 |
|---|---|---|---|
| 铜 | 电网、建筑、工业制造、电子 | 矿山产量、矿石品位、冶炼与回收 | 矿端供应、冶炼加工费、库存、终端需求 |
| 铝 | 建筑、交通、电力、包装 | 电力成本、产能约束、氧化铝与电解环节 | 铝价、氧化铝价格、电力成本、库存 |
| 铅锌 | 汽车电池、镀锌、建筑和工业 | 矿山、冶炼、回收 | 加工费、库存、终端订单、冶炼利润 |
| 黄金白银 | 投资、首饰、工业应用 | 矿产供应、回收、库存与交易 | 实际利率、汇率、投资需求、矿企成本 |
| 锂镍钴 | 动力电池、储能及合金等工业用途 | 矿山、盐湖、冶炼、回收与新增产能 | 原料库存、加工费、排产、项目投产进度 |
| 稀土及其他小金属 | 永磁、电机、电子、工业和特种用途 | 资源配额、开采冶炼、回收与贸易政策 | 产品结构、供给政策、下游订单、价格差异 |

**盈利传导的核心区别**

- 资源端的利润对金属价格、产量、品位和单位成本较敏感。
- 冶炼端可能受到加工费、能源成本、原料采购和副产品收益影响，金属价格上涨并不保证冶炼利润同步上涨。
- 加工端更依赖加工费、产品结构、客户认证、良率和终端需求。
- 对黄金等贵金属，宏观金融变量的影响可能强于传统工业需求；不能把所有有色金属统一归为制造业周期。

**反证与风险：** 新增矿山投产、需求替代、回收增加、库存累积、贸易政策变化和终端需求疲弱，均可能改变原先的供需判断。

### 4. 钢铁

**行业边界与链条**

- 上游：铁矿石、焦煤焦炭、废钢、合金、电力和运输。
- 中游：炼铁、炼钢、轧制与深加工；产品包括长材、板材、钢管及特钢。
- 下游：建筑与基建、汽车、机械、造船、家电、能源设备和出口。
- 需要区分长材与板材、普钢与特钢、建筑钢材与制造业用钢，避免用单一钢价代表全部企业。

**最重要的传导问题**

- 需求端：房地产施工、基建实物工作量、制造业订单、汽车与船舶生产、出口订单。
- 供给端：粗钢产量、产能利用率、检修、环保约束和新增产能。
- 成本端：铁矿石、焦煤焦炭、废钢和能源价格。
- 利润端：重点观察吨钢利润、产品结构、库存、产能利用率与现金流，而非只看钢材价格。

**首轮观察指标**

| 维度 | 优先指标 | 需要防止的误判 |
|---|---|---|
| 需求 | 建筑施工、基建工作量、制造业订单、钢材表观消费 | 项目规划不等于真实开工和钢材采购 |
| 供给 | 粗钢产量、产能利用率、检修与限产情况 | 名义减产与实际产量变化可能不一致 |
| 库存 | 钢厂库存、社会库存、不同品种库存 | 季节性累库不能直接判断需求崩塌 |
| 成本 | 铁矿石、焦煤焦炭、废钢、电力 | 原料涨价的影响取决于采购合同和库存 |
| 盈利 | 吨钢毛利、产品价差、现金流、应收账款 | 钢价上涨但原料涨得更快时利润仍可能下降 |

**反证与风险：** 终端需求不足、产量调整慢、原料成本上涨、出口环境变化和资金回款恶化，都可能让钢价反弹无法转化为可持续盈利。

### 5. 基础化工

**行业边界与链条**

- 上游：原油、煤炭、天然气、盐矿、磷矿、硫磺、能源和基础原料。
- 中游：化学原料、化学制品、化学纤维、塑料、橡胶、农化制品和部分新材料。
- 下游：农业、纺织、汽车、建筑、电子、家电、包装、医药和消费品。
- 该行业内部差异极大，应继续按产品和细分行业拆分，不用一个“化工景气度”概括所有产品。

**首轮拆分方法**

| 细分方向 | 主要观察逻辑 | 优先指标 |
|---|---|---|
| 大宗化学原料 | 供需、装置开工、产能投放和原料成本 | 产品价格、价差、库存、开工率、扩产进度 |
| 化肥与农药 | 农业需求、种植面积、农产品价格、政策与出口 | 价格、库存、开工率、出口、原料成本 |
| 化学纤维与合成材料 | 纺织服装、包装、汽车和工业材料需求 | 原料价差、下游订单、库存、产能利用率 |
| 特种化学品与新材料 | 客户认证、技术性能、良率和供应链替代 | 认证进度、客户结构、产品毛利率、研发投入 |
| 电子化学材料 | 半导体、显示和电子制造需求 | 客户认证、产能利用率、纯度要求、交付与回款 |

**利润传导的核心问题**

- 原料涨价时，产品价格能否同步上调？合同重定价需要多久？
- 行业新增产能是否集中投放？需求增长是否足以消化供给？
- 库存变化是主动备货还是被动累库？
- 高端材料的技术门槛、客户认证和切换成本是否形成持续竞争优势？
- 账面利润是否伴随现金回款，是否存在存货减值和应收账款风险？

**反证与风险：** 大规模扩产、同质化竞争、终端需求疲弱、原料价格反向波动、环保安全要求变化和客户认证失败，都可能使预期中的价差修复无法兑现。

## 三、五个行业的跨行业传导对照表

| 变化起点 | 可能受益的环节 | 可能承压的环节 | 必须核实的中间证据 |
|---|---|---|---|
| 煤价上涨 | 成本低、销量稳定且销售价格受益的煤炭企业 | 燃料成本上升且传导受限的火电及部分工业用户 | 企业实现煤价、长协比例、单位成本、电价机制 |
| 原油上涨 | 上游油气开采环节可能受益 | 炼化、交通运输及部分化工下游可能承压 | 原油采购成本、成品油与化工品价差、库存计价 |
| 铜价上涨 | 低成本矿山或资源端企业可能受益 | 铜材加工、部分电气设备与制造企业可能承压 | 矿山成本、加工费、合同传价机制、下游订单 |
| 钢材价格上涨 | 低成本且产品售价提升快于成本的钢企可能受益 | 建筑、机械、汽车等钢材使用方可能承压 | 吨钢利润、铁矿与焦煤成本、终端需求和合同价格 |
| 化工产品价差扩大 | 具有有效产能且成本受控的生产商可能受益 | 采购成本上涨且产品售价无法传导的下游用户可能承压 | 产品价差、开工率、库存、客户订单、现金流 |
| 终端需求走弱 | 具备低成本、低负债和高现金流韧性的企业相对抗压 | 高成本、库存高、扩产重和议价能力弱的企业 | 订单、库存、应收、资本开支、债务与现金流 |

**注意：** 表中“可能受益/承压”是条件判断，不是固定结论。实际结果由企业成本曲线、合同、业务结构、库存和估值共同决定。

## 四、后续公司与交易型开放式指数基金映射规则

本批次暂不直接把公司或基金名称列为推荐标的。建立映射时必须逐项核实：

1. 公司年报、招股书或公告是否披露对应业务，业务占比是否明确。
2. 公司处于资源、冶炼、加工、设备、贸易还是终端环节。
3. 盈利对价格的敏感度是否有证据，是否存在套期保值、长协和库存影响。
4. 交易型开放式指数基金跟踪的指数覆盖哪些细分行业，成分股和权重日期是什么。
5. 基金规模、成交额、费用、跟踪误差和集中度必须注明数据日期；不得仅凭名称判断纯度。
6. 产业链逻辑必须与当前估值、市场预期和风险分开评价。
